# Transit reporting missingness

Protocol only: no counts retrieved or findings established. This study will compare published bus-ridership dashboard summaries under explicitly synthetic reporting gaps. It will preserve zero, null and absent entries and qualify the reporting population, benchmark and bound assumptions.

Read [fixed protocol](PROTOCOL.md), [machine-readable design](protocol.json) and [source scope](SOURCES.md). The evidence target is a finite retrospective data-quality comparison, not passenger reliability or operational benefit. Formal-publication projects stay private.
