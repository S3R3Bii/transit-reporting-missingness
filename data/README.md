# Captured service facts

The projection contains only public federal MB agency-service/month UPT facts for 2019–2025. Original five-field SoQL responses and separate server controls are gzip-compressed with deterministic timestamps for inspection and independent parsing. Full portal metadata stays private; public metadata is limited to selected schema, source revision and license facts. No safety, individual-passenger or contact fields are retrieved.

Blank UPT represents an explicit source null on an existing row. A numeric zero is preserved. Absent source rows are identified separately when constructing a fixed cohort calendar. The later captured snapshot is not an original historical information vintage; its values are published entries rather than independently verified passenger truth. Manifest hashes identify exact responses, requests and projection bytes.
